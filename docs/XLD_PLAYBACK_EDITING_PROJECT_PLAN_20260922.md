- 版本：v1.0；日期：2026-09-22。
- 状态：R12–R16工程范围已实现；2026-09-23追加R17轨组整理已交付tracklayout.3/core.65。用户使用/听评及正式发行验收待进行。
- 开发基线：releases/0.5.0-dev.export.1；XLD core.59 / XML stems.13。
- 执行方式：个人项目，小步迭代，每轮形成一个可运行开发包，复用已有模块与结果。
- 依据：[当前审查](XLD_RIPX_GAP_AUDIT_20260922.md)、[R11 交接](../work/midi-export-20260922/HANDOFF.md)。
- 文档优先级：本文决定 R11 之后的近期范围和顺序；早期企划书与审查中的后续建议保留为历史。FL Studio／外部 DAW 往返已按用户最新要求暂缓。

## 1. 本阶段目标

用户在同一个时间轴总览里，使用原有 WAV 伴奏，单独把吉他或弦乐换成 MIDI；可以静音、独奏、循环核对，并修正一段被错误切碎的音符。保存、重开、融合与导出的结果要一致。

核心路径：
**打开已有结果 → 总览播放 → M/S 定位 → WAV/MIDI 同位置切换 → 聚焦修正 → 保存人工版 → 在原混音中复听 → 融合/导出。**

本阶段终点是这条路径可用，不以复刻完整 RipX 或完整 DAW 为完成条件。

## 2. 范围

### 本期实现（R12–R16）

- 所有播放入口共用播放/暂停、时间位置、主音量和循环规则。
- 修复草稿融合不一致、长音跨和弦漏计、部分和弦解析错误。
- 总览多轨 MIDI 试听，声部及子乐器 M/S、基础音量。
- WAV 轨道可见可听；逐声部 WAV/MIDI 切换，纯 WAV 环境声保留。
- Mega53 细分以替换父音源的方式参与混播，避免重复计入。
- 同音高音符合并、指定位置拆分，试听、撤销、保存闭环。
- 紧凑界面、必要状态提示与针对性回归。

### 后续候选，不计入本期完成条件

- 空 MIDI 补首音、删除最后一音/清空乐器，先解决身份稳定性。
- 复制粘贴、批量力度/时长、鼓类别编辑、跨乐器整理。
- 当前内部乐器、选区和所选轨道导出。
- 人工和弦明确作为分析参考；原稿/修订版临时 A/B。
- 更丰富的试听音源、踏板/弯音显示与播放，继而考虑编辑。
- 局部波形细读、可校正节拍/速度图、选区统计及动机标记。
- **FL Studio 与其他外部 DAW 的导回/往返：远期备选，用户重新提出需求后再排期。** 现有 MIDI 导出继续保留，本期无需安装或使用 FL Studio。

暂不纳入：新模型接入、自研模型、原 WAV 音符级重合成、谐波编辑、录音、VST 宿主、复杂效果链及全曲自动纠错。现有模型默认和备选保持。

## 3. 已有基础与必须保留的行为

已有多模型分轨/转谱、时间轴、基础音符编辑、草稿、人工版本、完整声部导出和融合。R11 已提供保存后重开及输出一致的工程证据。

继续遵守：
1. 原 WAV 与机器 MIDI 原稿不因编辑而覆盖。
2. 人工修改独立保存；失败时保留草稿和原活动版本。
3. 音符位置以歌曲秒数为准，不默认量化；120 BPM 文件时间基准不被误报为歌曲速度。
4. 多乐器 MIDI 的其他乐器、原有踏板/弯音等数据继续保留与校验。
5. M/S、音量、临时试听来源不改变正式版本、文件或导出范围。
6. XLD 拥有分析、修订和试听；XML 消费结果。无需搬迁分析职责。
7. 旧开发包和真实分析目录保留，新功能在隔离夹具中验证。

## 4. 界面与监听约定

### 页面分工

- 转谱页：生成模型结果、选用版本，提供明确标注来源的试听入口。
- 时间轴：总览试听、M/S、循环、聚焦编辑，沿用现有页面。
- 底部播放器：唯一全局播放控制和当前声音状态。

轨头一行：
**声部名 ｜ M ｜ S ｜ WAV/MIDI ｜ 音量**

模型名、文件路径、版本详情收进展开信息。折叠、隐藏、选中和聚焦仅改变视图，不暗中改变混音。编辑工具按选区出现；总览和聚焦共享同一播放位置。

### 全局播放

- 顶部或底部来源切换为“原曲 / 工作混音”；同位置 A/B，不从头播放。
- “原曲”是完整录音，此时逐轨 M/S 不作用于录音内容；需进入工作混音才能听去掉某声部后的组合。
- 全部入口共用播放、暂停、空格、定位、循环和主音量。主音量为零必须控制所有已接管音源。
- 细分预览依据 timeOrigin 映射到歌曲秒数；越出预览范围停止该试听并明确提示，不伪装成完整音轨。
- 页面切换可继续当前声音，但其来源必须始终在底部可见；启动新试听替换旧试听，不允许隐形叠播。
- 换歌曲停止并重置当前监听；本期轨音量/M/S仅保留当前曲目会话，不新增完整工程文件。主音量延续已有本机偏好。

### M/S 与声部层级

- 父声部持有一个 WAV，可关联多条 MIDI 子乐器。
- 父组 M 静音全部子轨；M 优先于 S。多组或多个子轨可以同时 S。
- 组 S 选择该组未静音的子轨；子 S 仅选择该 MIDI 乐器。无任何 S 时，所有未静音的轨发声。
- 被其他轨 S 暂时排除的轨有区别于主动 M 的显示，提供清除全部 M/S。
- WAV 模式下只播放父源一次，子乐器 M/S 不控制该 WAV，界面明确禁用相应子控件；切到 MIDI 模式恢复子轨设置。
- WAV 模式下保留的 MIDI 子轨 M/S 不参与当前监听或全局独奏判断；切回 MIDI 后才恢复生效，避免“全部 WAV”被隐藏的子轨 S 意外限制。
- 选中某条 violin MIDI 不表示存在独立 violin WAV。
- M/S 不减少导出内容；导出范围由独立规则决定。

### 来源切换与缺失

- 工作混音提供“全部 WAV”“有结果用 MIDI”“仅 MIDI”三个预设；可再逐组修改。
- “有结果用 MIDI”中，无 MIDI 的轨明确保留 WAV；“仅 MIDI”明确显示被排除的纯 WAV 轨。
- MIDI 为空/未生成时仍可听 WAV；“有结果用 MIDI”仅选择有效且有音符的结果，零音符结果明示为空并保留 WAV。没有 WAV 的可用 MIDI 仍能在 MIDI 模式显示和播放。
- 来源缺失或切版导致失效时，暂停受影响的试听并说明，不偷偷换成另一个模型。
- 显示机器版/人工版/未保存草稿；全组 MIDI 试听中，存在草稿的乐器使用该草稿，其余乐器使用当前已保存版本。

### R12：统一播放与试听来源

工作：
- 将主播放器、时间轴 MIDI/WAV 和细分试听接到一个播放会话。
- 保留现有各音源实现，集中播放状态、控制命令和时钟映射，不先重写合成器。
- 转谱页明确 WAV/MIDI；没有结果的选项说明原因，不以“试听”代指不明来源。
- 底部显示歌曲、声部、来源、位置及播放状态。

验收：
- 从每个入口播放后，主音量=0均静音；空格/暂停控制正在响的声音。
- 跳转和循环不切回另一播放器；跳入长音中间仍可正确续听。
- 细分试听替换旧试听；同曲换页面无隐藏声源，换曲/关窗无挂音。
- WAV/MIDI切换保持逻辑时间；核对异步加载后不得启动已被取消的旧来源。

本轮不加多轨混音、M/S或新音源库。

### R13：结果一致性与分析计算修复

分为三个可独立验证的小任务：
1. 融合与一键 MIDI 最终融合在服务入口检查相关活动版本及草稿；默认存在相关未保存草稿就停止并引导保存/撤回。历史其他版本草稿不误阻断当前输出。不自动保存或丢弃用户修改。提交前重新核对来源/版本，不能只依赖按钮状态。
2. 和声统计按音符与和弦区间的实际重叠时长计算；演奏方式的起音统计保持独立。
3. 覆盖当前引擎实际和弦标签，未知标签显示未知；修复 C9、Cmaj9、Cm7b5、C7b9 样例。标明当前和声参考来自哪个模型。

验收：
- 有相关草稿时不能静默成功融合旧稿；保存后融合记录和实际音符对应人工版。
- 跨和弦长音在后一段仍计入，权重不超出区间时长。
- 已知和弦例子计算正确，不能识别的标签不猜测。
- 原结果文件不变，撤回草稿后正常融合。

人工和弦“备注/确认修正”的覆盖规则另排，不把它作为 R14 前置条件；本轮明确提示其尚未成为条带参考。

### R14：总览多轨 MIDI 与 M/S

工作：
- 不进入聚焦也能播放全部可用 MIDI；父声部/子乐器 M/S、父轨基础音量。
- 与现有草稿试听衔接，切换聚焦不改变正在监听的组合。
- 多轨共用时钟和输出总线，切换/静音采用短渐变避免爆音。
- 测量真实并发音符，调整原单轨 64 复音限制；过载行为明确，不能把延音无提示抢断。

验收：
- 播放中即时 M/S，多个 S 和父子层级按约定工作；主音量覆盖所有轨。
- 总览→聚焦→返回保持位置和声音组合。
- 跨轨共用定位与循环；同时发声音符超过旧64上限的用例不静默丢掉长音。
- 监听状态变化不修改 MIDI、活动版本或输出范围。
- 密集真实片段进行实际 AudioContext 验证，记录掉音/CPU表现。

此轮已有可用的多轨 MIDI 试听，不等待 WAV 混播完成才交付。

### R15：WAV/MIDI 混播与来源关系

实施记录（2026-09-23）：已交付 hybrid.1 / core.63。本机工程验收通过：MEGURI WAV/MIDI切换、单份父WAV、互补替换、原曲A/B、60秒连续混播及约12次短循环；有界缓存与来源拒绝、完整编辑保存/导出/融合/恢复通过。用户听评待进行，自动验收不作听感结论。详见[交接](../work/hybrid-20260923/HANDOFF.md)。

工作：
- 轨道清单取可用 WAV 与 MIDI 的并集；纯 WAV 轨可 M/S、循环，显示轻量波形概览。
- 逐声部 WAV/MIDI 切换，接通三个预设与原曲 A/B。
- WAV 根据唯一音源缓存，strings 子轨不重复加载/播放父 WAV。
- 基础分轨使用同一来源集合；整曲 Mega 细分通过 target+residual 替换父源。
- 第一版每个父源一次只选一组互补细分，不新增任意链式分解图。

来源限制：
- other细分替换other；从整曲提取的target+residual替换的是整曲参考，不直接追加到全套基础轨。
- 独立提取的多个target不默认互补；来源缺失、时间基准不符或重复父源拒绝加入并说明。
- 短预览继续作局部对照，不进入“全曲混音”。
- 使用相匹配的 target/residual 增益；分轨响度变化不以独立归一化掩盖。

验收：
- 在同位置听“吉他MIDI+其余WAV”“弦乐MIDI+其余WAV”，无持续双响或位置重置。
- 一个strings WAV只响一次；没有MIDI的other/glitch仍可见可听。
- 合法细分替换父源后无重复计入；非法来源组合可解释地拒绝。
- 长曲记录峰值内存、首播加载和跳转表现，确认没有子轨重复解码；连续播放与多次循环无可感知漂移。
- 若整曲解码占用不适合当前机器，本轮内改为有界载入/分段方案后再标记通过；不预先搭通用流媒体框架。

R15通过即达到本期最重要里程碑：统一总览下的M/S与混合来源试听。

### R16：合并/拆分与修正闭环

实施记录（2026-09-23）：已交付 noteshape.2 / core.64。同音高相邻选择合并、光标或精确秒数拆分、橙色预览/取消、一步撤销/重做与混播复听接通。六链、真实MEGURI写入回读、保存/重开/导出/融合、原稿哈希与中英文界面验证通过。真实重复起音与错误碎音仍需人工听评；不声称恢复揉弦。详见[交接](../work/note-shape-20260923/HANDOFF.md)。

工作：
- 在当前乐器中合并至少两个明确选中的同音高音符，跨度取首起点至末结束。
- 仅允许该音高上相邻、且之间没有未选音符的选择；先预览，不自动按间隔扫描全曲。
- 合并默认保留最早音符力度；明确提示结果，可在现有属性中调整。原控制事件不凭空合成或自动改写。
- 单音在光标指定的内部时刻拆为两个，保留音高/力度；满足现有最小时值与写入校验。
- 每次合并/拆分为一步撤销；在同循环区间听改前/改后草稿，不改变正式版本。
- 保存后用工作混音复听，再使用既有整声部导出/融合。

验收：
- 选定延音碎片可以合并、试听、撤销、重做。
- 拆分在边界或产生不可保存短音时给出原因。
- 修正后保存、重开、融合/导出数据一致，其他乐器和原稿保持。
- 在 MEGURI 实际片段区分碎音与真实重复起音；合并不被宣传为恢复原演奏揉弦曲线。
- 不需要 FL Studio：导出文件以独立读取检查音符/表达数据，听评在 XLD 内进行。

只明确四类状态：
- 音源：trackId、父来源/run、文件身份、timeOrigin及有效范围。

- 输出：当前已保存版本及显式输出范围。

试听状态不写回模型记录。空轨编辑另做稳定乐器身份设计，不在本期默默改变现有索引约定。共享播放控制可以抽出一个小模块，但不新增数据库、通用插件平台或长期迁移工程。

## 7. 验证与交付

固定两个真实样本即可起步：
- MEGURI：30–60秒弦乐/吉他片段、多乐器与延音，再用整曲检查资源占用。
- toe《goodbye》：鼓的起音、类别与循环边界。已有结果不足时先记录缺口，不为了界面验收默认重跑昂贵模型。

另用小型合成夹具覆盖：超过64复音、零音符、有WAV无MIDI、跨和弦长音、扩展和弦、来源切换、重叠父源和未保存草稿。这些只验证逻辑，不能当作音乐质量评分。

每轮执行：
1. 为本轮明确输入、输出、控件、失败行为和不改事项，写简短SPEC。
2. 针对真实缺陷添加能先失败的测试，不堆仅检查实现字符串的测试。
3. 运行受影响模块测试及必要整合回归；变更播放必须验证真实AudioContext/打包窗口。
4. 在隔离复制的MIDI与只读参考音频上操作；核验机器原稿哈希不变。
5. 输出新开发包、HANDOFF、测试证据和短使用步骤，更新真实版本入口。
