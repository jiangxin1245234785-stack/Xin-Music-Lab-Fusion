# Xin Music Lab · {{VERSION}} · Windows 界面预览

本包提供 XLD / XML 交互界面和模型接入接口，不包含模型权重、Python 或 AI 依赖。

## 启动

1. 将整个 ZIP 解压到可写目录，不能直接在压缩包里运行。
2. 打开 XLD.exe：选择曲库，浏览与播放本地音乐。
3. 打开 XML.exe：使用音乐可视化。
4. 按 F1 查看帮助；需要分轨/MIDI/段落/和弦时，阅读 MODEL-SETUP.md，自行安装对应模型及依赖，并修改 runtime.json。

没有模型时，分析卡片显示不可用，这是正常状态。只需安装想用的后端，不要求一次装全。仅下载一个权重文件仍不足以运行，模型对应的 Python 依赖也需要安装。

不包含音乐、生成结果或开发者设置。缺少的运行路径不会阻止打开界面。模型由作者提供，请自行从上游下载并完成所需授权；本项目不提供模型镜像或共享账号。

## 范围

这是 core.26 / stems.11 验证基线的界面发行包，模型默认以随包 models.json 为准；不包含此后尚在迭代的引擎。Windows x64 本机界面验收；不是已完成全新 Windows、所有 GPU 与全部模型验收的稳定版。

保留完整目录移动程序；用户曲库和分析结果位置独立。模型自配说明属于接入文档，不是全自动安装器。程序未签名。遇到问题请提供版本与操作步骤，不要提交访问令牌或完整音乐。
