从一首歌到分轨与 MIDI

XLD 管理曲库与音乐分析；XML 负责可视化，可以读取 XLD 的分析结果。点击应用标题旁的版本按钮，或按 F1，随时返回这里。ⓘ 可查看版本与运行环境路径状态。

开始使用寻找输出升级与回退另一台电脑验收

音频存储管理

  1. 右上角“资料库 → 存储管理”，扫描当前分析资料库，按体积从大到小查看结果。
  2. 先把满意的结果标为“保留”。可以搜索歌曲、模型或目标，筛选细分 / 基础分轨 / 已保留。
  3. 勾选不需要的结果，或点“选择可清理项”。批选只针对当前筛选内容，跳过已保留、存在依赖和当前使用的基础分轨。
  4. 默认“移至回收站”；清空 Windows 回收站后才释放磁盘空间。如需直接释放，明确选择“永久删除”，再核对确认框中的歌曲、数量与体积。确认框默认取消。

清理单位是一次完整输出：原始输入副本、目标、剩余及相应试听副本一起移除。原曲库、模型、MIDI 文件、段落和人工标注不删除。原始输入副本也属于生成结果，与原曲文件不同。

基础分轨如果仍被细分或 MIDI 使用，会显示保护原因。第一版不提供强制删除依赖；可先清理不需要的细分结果。MIDI 依赖的基础分轨保留，以免工作台失去关联。取消“保留”后才可选中该结果清理。

小型索引保留，应用读取时会把缺少音频的结果视为未生成；同设置可重新计算。从 Windows 回收站恢复原目录后，未被新计算替换的索引可继续使用。删除后不立即重算，回收站恢复更方便。

目前不自动压缩、降采样或转换 FLOAT 音频，也不会自动清理用户文件。保留常用结果，试验时优先使用 30 秒预览，定期清理不满意的版本即可控制增长。只有当前资料库会被扫描；旧测试目录和其他开发缓存不在这次清理范围。

弦乐 MIDI

  1. 先完成 Mega53 整曲弦乐提取；30 秒试听结果不进入整曲 MIDI。
  2. MIDI 页“弦乐音源”显示当前可用的整曲结果，包含目标、来源、时长和结果标识。选择一份作为可选弦乐声部。
  3. 选择 strings 后可单独生成或试听；一键 MIDI 会自动包含已选弦乐，融合时保留对应乐器音色与时间。
  4. 单声部目录对应当前音源和模型；本曲目录包含历史输出。切换音源不会混用 MIDI 缓存。
  5. “不加入弦乐”只取消本次一键与融合使用，不删除历史输出。存储管理会保护已有 MIDI 依赖的细分 WAV。

弦乐可选 MuScriptor Large（默认）、Medium、YourMT3+ 与 Basic Pitch；这些模型输出离散音符并使用固定力度，不还原连续揉弦或演奏轻重。弦乐组、小提琴、中提琴、大提琴、低音提琴一次只选一项，避免重复叠加。

紧凑工作台

MIDI 页左侧选择声部和模型，右侧一键生成与融合。弦乐来源位于上方，可选择已有整曲结果。较窄窗口自动上下排列。使用说明、模型说明和融合声部明细可点击展开；任务状态和目录按钮直接显示。

弦乐与鼓：MuScriptor 对比

MIDI 页选择 strings 或 drums，可使用 Medium 或 Large。弦乐默认 MuScriptor Large、鼓默认 ADTOF，YourMT3+ 保留备选。新模型固定力度，按来源与模型独立保存；一键生成跟随选择。旧结果可以随时切回，或在确认后移入回收站。

模型版本与历史结果

每次 MIDI 转谱都记录生成它的模型版本。将来某个模型更换权重或参数后，旧结果不会消失：卡片标为“旧模型版本”，仍可打开目录、试听并参与融合；但它不会被当作当前版本的缓存复用，点击“生成 MIDI”会用当前版本重新转谱，旧的运行原样保留。删除某次结果只影响这一次运行，不影响同一模型的其他版本和共用的 WAV。本版没有更换任何模型或默认，现有结果全部按当前版本读取。同一模型多个版本之间的切换、回退与批量清理留待后续版本。

一键 MIDI

  1. 打开 XLD.exe，从左侧曲库选择歌曲；首次使用可点“更换曲库”。单击选择工作曲目，双击播放。
  2. 进入“分轨”，使用默认模型生成 WAV。已有有效结果可以直接复用，也可以选择备选模型。
  3. 进入“MIDI”，查看一键计划中的 bass、piano、guitar、drums 模型，然后点“一键生成 MIDI”。如要更换模型，先在单声部菜单中选择。
  4. 完成后点“打开本曲 MIDI 目录”；“打开融合 MIDI”可交给关联的软件处理，也可以在 FL Studio 中手动导入。

默认复用有效缓存。“重新生成”重算本次 MIDI，不重新分轨。取消或失败会停止剩余步骤，已经完成的文件保留；再次运行可以复用它们。

如果有音符的声部不足两个，会保留单声部结果并跳过融合。空 MIDI 表示没有识别到音符，不等于文件没有保存。

Mega 53：全部目标

在“分轨 → 细分”选择 Mega 53。输入来源可选原曲，无需先生成六轨；也可细分当前已有的 other、guitar、piano、bass、drums 或 vocals。默认仍使用 other 与弓弦乐组，之前完成的弦乐结果可直接读取。

按“弦乐 / 吉他与拨弦 / 键盘与合成器 / 管乐 / 鼓与打击乐 / 人声”选择目标，也可选“全部目标”浏览 53 项。“弓弦乐组”和“弦乐总类”是不同输出，“吉他总类”和“电吉他 / 原声吉他”也不同。

每次提取一个目标，范围可选整曲或 30 秒预览。输入、目标、设备及范围分别缓存；可取消、保留结果、打开目录，并切换原始输入 / 目标 / 剩余试听。Bowed 与 AudioSep 仍是 other 的预览备选。

53 项是可提取的目标，并非 53 条互斥音轨。单次目标与剩余组成当前输入，不要再叠加原输入，也不要直接相加独立提取的不同目标。合成器不等于所有电子采样与 glitch，电吉他也不等于失真吉他专用模型。细分结果暂不自动进入 MIDI。

original.wav、target.wav、residual.wav 保留 FLOAT 原始输出；需要时另存 listen- 前缀的共用增益试听文件。应用自动播放试听文件。显存不足时自动缩短分块，再回退 CPU；CPU 使用系统内存，速度较慢。

MEGURI 的 8:17–8:47 原曲预览已准备：电吉他、原声吉他、吉他总类、合成器、弦乐总类。选原曲 / 30 秒预览 / 起点 497 / 自动即可读取。该片段按能量选取，声音质量由你试听判断。

三个目录入口

入口打开的内容
打开 WAV 目录当前分轨模型的六个声部音频。
打开本曲 MIDI 目录本曲 MIDI 总目录，包含各声部与融合结果；不受“原曲”试听选择影响。
打开声部 MIDI 目录当前声部、当前模型的有效结果。

融合文件名为 merged.mid，单声部文件按 bass、piano、guitar、drums 命名。各次结果分开保存；“MIDI 融合”区的打开按钮定位当前组合。切换 WAV 模型后，会显示对应来源的 MIDI，避免混用不同分轨结果。

目录按钮为灰色时，先确认当前歌曲已生成相应结果，再点刷新。任务失败时查看任务栏中的具体提示。ⓘ 的环境检查只检查路径；模型卡片显示各模型是否可用。

如何判断还原效果

鼓目前输出底鼓、军鼓、通鼓、踩镲、镲片五类，力度固定为 100。导入 FL Studio 后使用兼容 GM 映射的鼓音源。鼓点时间保留，但滚奏、弱音和镲片奏法可能简化。

弦乐与部分电子环境音仍在 other.wav 中，目前不纳入一键 MIDI。转谱是可编辑的音符近似；音源选择也会影响试听效果。

升级、移动与回退

  1. 先关闭 XML 与 XLD，再打开新版本目录中的 EXE。常规候选版沿用原偏好；本整曲开发版使用独立偏好，沿用前一开发版的分析目录。
  2. 保留旧版本即可回退：关闭新版本，重新打开旧版本。不要同时用两版运行分析。
  3. 移动整套工具时，程序与运行环境需要一起移动并保留相对结构：
工具目录/
  releases/{{VERSION}}/XLD.exe、XML.exe、runtime.json…
  runtime/0.5.0/…

不要只复制 EXE。音乐文件和分析结果不包含在程序包中；换电脑后，需在应用中重新选择对应目录。运行目录需要允许当前用户写入模型缓存，建议放在个人可写的数据盘。

无 Python 的另一台 Windows：简短验收

本机窗口与模型检查已通过；下面这组干净系统检查仍待完成。

先双击“检查环境.cmd”：无需另装 Node/Python，逐项检查段落、和弦、分轨和四声部 MIDI 的运行环境与模型。每项最多等待两分钟，可按 Ctrl+C 停止。完成后显示报告目录；中文摘要与 JSON 保存在本机 %LOCALAPPDATA%/XinMusicDiagnostics/，每次单独保存。此检查不执行歌曲推理，也不验证音质。报告包含本机路径，分享前可自行删去个人信息。
  1. 复制程序与运行环境，断网启动 XLD/XML，确认版本正确、没有缺失环境提示。
  2. 选择一段自己的音频，确认播放、暂停和定位正常。
  3. 在 XLD 完成段落、和弦、分轨与一键四声部 MIDI；分别打开 WAV、本曲 MIDI、融合文件。
  4. 取消一次任务后重试；重新打开应用，确认选曲、偏好和已有结果可以恢复。
  5. 从 XML 打开 XLD，确认选曲一致；返回 XML 更新结果并试听分轨。

记录 Windows 版本、是否有 NVIDIA 显卡、失败步骤和任务提示。当前仍为个人本地候选版，不代表全新 Windows 或所有显卡均已验证。

Quick reference

XLD owns analysis; XML visualizes its results. Select a song → separate WAV stems → generate all MIDI → open the song MIDI folder. The batch includes bass, piano, guitar and drums, then merges nonempty parts. Completed results survive cancellation and can be reused.

Keep the release folder and runtime/0.5.0 together with their relative layout. Close both apps before upgrading or reverting. Click the version button or press F1 for this guide; ⓘ checks runtime paths. This is a release candidate; clean-machine acceptance remains pending.
