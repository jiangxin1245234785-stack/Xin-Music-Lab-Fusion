开始使用 / Getting started

完整解压后打开 XLD.exe。顶部“配置 / Setup”可选择曲库、生成目录与模型环境。

Extract the full archive and open XLD.exe. Setup in the header provides library, output and backend configuration.

1 · MIDI 保存与导出 / MIDI save & export

配置窗口可联网安装独立 Python 和 MIDI 依赖，预留 1 GB。安装成功后点击“保存配置”，关闭并重新打开应用。不更改系统 Python，不包含 AI 模型。

The optional installer creates a separate Python/MIDI environment. Reserve 1 GB. After installation, save the setup and reopen the app. It does not modify system Python or include AI models.

2 · AI 分析 / AI analysis

分轨、段落、和弦与 MIDI 转谱需要另行安装后端。按 MODEL-SETUP.md 配置，可在窗口中选择解释器和目录，不必手改 JSON。MuScriptor 等受限权重需由本人在官方页面授权。drums、guitar、strings 等声部可独立选择模型。

Separation, sections, chords and MIDI transcription require separately installed backends. Follow MODEL-SETUP.md, then use the interpreter/folder pickers. Gated weights such as MuScriptor require your own official authorization. Parts such as drums, guitar and strings support individual model choices.

3 · 使用工作台 / Workbench

选择曲目后进入分析面板；生成后在时间轴试听 WAV/MIDI，使用轨头的静音、独奏、音量与折叠。人工 MIDI 修订与机器结果分别保管，可在结果面板管理版本，导出面板输出 MIDI。

Select a track and use the analysis panel. Listen to WAV/MIDI on the timeline; use track-header mute, solo, volume and folding. Manual MIDI revisions remain separate from machine results. Manage versions in Results and export MIDI from Export.

问题反馈 / Troubleshooting

缺少模型不影响普通播放。依赖和文件检测不代表实际推理通过；先试短片段。可导出脱敏诊断。预览版尚待干净 Windows 与更多 GPU 验收。

Missing models do not prevent ordinary playback. Availability checks do not certify inference; test a short clip first. Export redacted diagnostics if needed. Clean-Windows and additional GPU validation remain outstanding.
