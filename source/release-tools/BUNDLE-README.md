# Xin Music · {{VERSION}}

本版不更换模型，不改默认、选项与精度；整理的是“结果如何记住自己由哪个模型版本生成”。

每次 MIDI 转谱都有独立记录。将来升级某个模型后，旧结果仍可查看、打开目录、参与融合，卡片标注“旧模型版本”；它不会被误当新版本的缓存复用，点击生成会用当前版本重算并保留旧运行，删除只影响那一次运行。清单新增输出文件摘要，旧结果无需迁移。

现有 MEGURI、toe 等全部结果按当前版本读取，界面与 muscriptor.4 一致；融合结果继续命中，另记录各声部来源版本。同一模型多版本切换、回退与批量清理留待后续版本。

双击 XLD.exe 开始，XML.exe 负责可视化，F1 查看使用说明。history.1 使用独立偏好；muscriptor.4 与更早版本保留。保留 releases/{{VERSION}} 与 runtime 的相对目录，不要单独复制 EXE。仅本机开发版，未做干净 Windows 验收。
