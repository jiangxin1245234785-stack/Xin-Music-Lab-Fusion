# Xin Music · 本机候选版 0.5.0-rc.1

双击 XLD.exe 进入分析工作台；XML.exe 进入音乐可视化。首次使用请先关闭旧开发窗口，避免单实例机制切回旧窗口。

程序和 Electron 已随包提供，不需要从开发源码启动。XML 的“在 XLD 中分析”直接启动同目录 XLD.exe。曲库、分析输出、人工标签、界面偏好沿用原有设置。

这是当前电脑的候选版。runtime.json 显式指定已有 Python、模型及旧分析脚本；这些外部目录以及 Python 基础环境仍须保留。不是可直接复制到其他电脑的离线包。检查项和下一步见项目 work/release-prep-20260915/HANDOFF.md。

升级使用新的完整发布目录，不在运行中覆盖旧版本，不删除分析数据。回退时关闭新窗口，启动旧版或原 start-dev.cmd；本轮未修改数据格式，也未替换原安装产品。

验证阶段保留 Beta 标识和旧配置身份，避免切换名称造成曲库配置丢失。完整长曲日常试用和干净机器验收完成前，不标为稳定版。
