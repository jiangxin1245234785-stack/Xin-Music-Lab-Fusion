# Xin Music Lab · {{VERSION}}

此包使用**外部配置的分析运行环境**。程序目录包含桌面应用，不包含完整模型与 Python 环境；需要由提供测试包的人完成 runtime.json 配置。

## 开始使用

1. 保留完整程序目录，先关闭正在运行的旧版本。
2. 打开 **XLD.exe** 进入分析工作台；**XML.exe** 用于音乐可视化。
3. 在 XLD 选择自己的曲库和分析资料库。
4. 从一首歌的分轨与试听开始，再运行单声部或一键 MIDI。
5. 用结果旁的目录按钮获取输出，按 F1 查看操作说明。

## 环境缺失

运行 **检查环境.cmd** 或查看界面的环境状态。如果提示找不到模型 / Python，请向提供测试包的人索取对应配置，不要反复点击生成。

当前包不代表通用离线安装器，也没有完成干净 Windows 全流程验收。请勿只复制 EXE，或假设开发者电脑的目录在自己的电脑上同样存在。

## 升级与反馈

保留原曲和分析资料库；关闭应用后使用新版本完整目录，不在运行中覆盖文件。反馈时附应用版本、系统 / 显卡、模型、操作步骤和错误文字，无需提供完整歌曲或登录凭据。
