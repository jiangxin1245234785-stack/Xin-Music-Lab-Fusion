# XLD 存储管理第一版
1. 输入：当前分析资料库，后台异步扫描；不扫描或修改原曲库、模型目录。
2. 列表：基础六轨与细分运行目录，歌曲/模型/目标/范围/日期/体积/保留/依赖；总量及 WAV 用量。
3. 控件：资料库中的存储管理弹窗、刷新、搜索、类型筛选、选择可清理项、逐项保留/取消保留/打开目录、批量清理、关闭。
4. 清理：默认移至回收站；可显式选择永久删除，应用原生确认列出数量和体积，默认取消。
5. 不自动执行用户数据清理；完成开发时只在临时夹具验证删除。
6. 已保留的结果跳过；存在细分或 MIDI 依赖的基础分轨暂保护；原曲/MIDI/段落/人工标注不删除。
7. 删除单位是完整的已识别输出目录；保留小型索引，旧索引自然判定缺失，可重算；回收目录后旧索引仍可用。
8. 删除前重新扫描核对目录内容和指纹、拒绝链接/未知文件/路径越界，分析任务运行时不允许清理。
9. 默认不压缩或降低 FLOAT 精度，不新增依赖；沿用 Electron GUI 和独立 Python。
10. 发布 storage1 独立开发版，沿用开发资料库；保留 mega2 与正式候选版。
11. 验证：扫描真实目录只读、路径/依赖/保留/变更保护、夹具清理、界面控制器与打包校验；用户本机范围。
12. backlog：自动归档/跨盘迁移、无损浮点压缩、只保留目标与按需重建试听副本。
