# SPEC — 分轨与 MIDI 流程整理
1. 范围：沿用 XLD 分析所有权和现有模型，仅修正来源、选择、状态及输出引导。
2. 输入：当前歌曲已启用的基础 WAV 分轨；MIDI 支持 bass/piano/guitar/drums。
3. 细分：Mega53 独立结果继续试听/保留；明确尚未进入 MIDI 或融合。
4. UI：独立 MIDI 声部选择与试听按钮；当前 WAV 来源；模型当前启用/缓存状态；一键计划逐项状态。
5. 试听选曲不改变 MIDI 目标；模型预选不激活缓存，点击生成/使用成功后激活。
6. 分轨与 MIDI 的重新生成选择分开记忆，切歌重置，防止跨页误重算。
7. 完成/失败/取消消息绑定歌曲及 WAV 来源；零音符结果明确显示，目录仍可访问。
8. 一键沿用串行四声部加融合，复用缓存，失败/取消停止并保留已完成结果。
9. 输出及覆盖策略不变；不修改音频、模型、已有机器结果或人工标注。
10. Windows 个人开发版，复用现有 Electron/Python/runtime，无新增依赖与打包框架。
11. 验证：控制器回归覆盖真实操作序列；XLD/XML 既有测试；发布包一致性与环境检查。
12. v2 backlog：细分结果转 MIDI、新转谱模型、跨实例任务协调。
