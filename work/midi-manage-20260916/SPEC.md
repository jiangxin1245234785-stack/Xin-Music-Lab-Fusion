# 弦乐默认模型与 MIDI 删除
1. 将 strings 默认转谱切换为 YourMT3+，Basic Pitch 保留备选；其他声部默认不变。
2. 首次升级迁移旧的 strings Basic Pitch 选择；之后保留用户手动选择。
3. MIDI 页增加“删除 MIDI”，作用于当前歌曲、音源、声部、模型的当前生成结果。
4. 删除前确认具体曲目、声部和模型；仅生成的 MIDI 与 notes 文件移至 Windows 回收站。
5. 保留原曲、WAV、其他模型结果及已有融合文件；索引保留以支持回收站恢复，缺失文件不视为有效缓存。
6. 删除正在启用的旧结果时，若已有有效默认模型结果则启用它，否则该声部待生成/待启用。
7. 删除后刷新模型状态、一键 MIDI、融合和目录按钮；正在分析时禁止删除。
8. 复用现有 Electron 界面、运行环境与存储路径守卫；无新依赖、无新模型运行。
9. 仅在隔离样本上验证删除，不代替用户批量清理真实歌曲。
10. 验证取消/失败/路径边界/源变更/缓存恢复及真实窗口；交付可回退开发版。
