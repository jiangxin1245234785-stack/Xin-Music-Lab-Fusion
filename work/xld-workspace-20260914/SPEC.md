# XLD 工作台整合（第一轮）
1. 默认进入工作台，曲库常驻左侧，专辑与曲目分层浏览。
2. 工作台提供概览、段落、和弦、分轨、MIDI 五个入口。
3. 保留全部现有模型及默认、备选关系，不新增算法或细分音轨。
4. 概览读取当前歌曲已有结果，提供去处理、查看结果的入口。
5. 当前选择、当前播放与正在处理的歌曲分别显示。
6. 任务进度、取消与播放器不随工作区滚动消失；终态可收起。
7. 分轨与 MIDI 共用真实音源选择，缓存、模型结果与试听逻辑不变。
8. 段落和和弦复用现有分析、时间轴、长曲分段及人工标签功能。
9. 资料库、日志、结果管理降低展示层级，仍可直接访问。
10. 不自动播放、不自动运行分析；切换页面不打断任务。
11. 保留 XML 展示、XLD 分析的职责，保持既有接口与数据格式。
12. 完成开发源集成、真实缓存界面验收、回归检查与交接日志。
