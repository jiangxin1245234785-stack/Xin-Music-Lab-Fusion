# XML / XLD 使用流程收口
1. 输入：当前选曲及 XLD 已有分析结果；本轮不新增分析算法。
2. XML 默认展示声部试听、结果状态、输出目录；分析操作折叠为「分析选项」，主入口为「在 XLD 中分析」。
3. XML 返回焦点或点击「更新结果」时重新读取当前曲目的时间线/WAV/MIDI，不重新加载音频或重扫整个曲库。
4. 时间线更新保留播放位置/状态及声部；所试听分轨被替换或失效时回原曲并保留位置。
5. 单曲结果读取遵循 XLD 目录身份、旧目录兼容和既有 manifest 校验；损坏结果不替换当前显示。
6. XLD 开发版复用已有窗口，并接收 XML 新的选曲请求；选曲不自动播放，不打断当前任务。
7. 交接请求写到当前共享分析目录一次，使用原子替换；不添加任务队列、常驻服务或跨程序分析锁。
8. Windows Electron 开发版；复用现有环境，无新依赖、无 EXE 打包，不修改安装产品。
9. 校验手动/自动更新、暂停和播放保持、分轨失效回退、快速换曲隔离、双语控件和 XLD 窗口复用。
10. 更新源码、项目日志、交接和试用说明；保留旧入口兼容。
11. 后续：跨程序分析互斥、安装包、MIDI 编辑，均不在本轮。
