# MIDI 融合 · 小功能
1. 复用 XLD Electron 工作台与已安装的 MIDI Python 环境，不新增依赖或打包。
2. 输入为当前歌曲、当前 WAV 来源下已启用的 bass/piano/guitar MIDI，至少两个声部。
3. 合成一个 Type 1 多轨 MIDI，独立乐器/通道，保留绝对时间、力度、弯音及控制器。
4. 不量化、不重新转谱、不混合不同备选模型；不改写源 MIDI 或源音频。
5. 输出到歌曲分析目录 midi/merged/来源指纹/merged.mid，附来源清单。
6. 相同输入复用结果，源模型或 WAV 改变后只使用匹配的新结果。
7. MIDI 页提供来源摘要、融合按钮、打开 MIDI、打开目录与状态提示。
8. 共用 XLD 任务互斥、进度和取消；坏文件导致整次失败，已有结果保留。
9. 通过外部 MIDI 软件试听；本轮不增加音色库、内置合成器或编辑器。
10. 使用真实 WEG 缓存验证音符/控制器/时间一致与界面操作，交付开发源和简短交接。
