# YourMT3+ 对比与单屏工作台
1. 输入已有 Mega53 整曲 strings WAV，增加 YourMT3+ 可选模型，保留 Basic Pitch。
2. 输出独立 MIDI/notes/运行信息，沿用按音源和模型隔离的缓存与激活机制。
3. 先以 Flowers of Romance 同源片段/整曲比较；保存原始输出，不加连奏修补。
4. 现有 Electron GUI 保留；单声部、整曲、目录与状态尽量在 1180×780 普通字号一屏可达。
5. 分轨页基础分轨与细分并排，说明与次要参数折叠；任务条和曲目区合并压缩。
6. 运行环境使用独立 YourMT3 附加目录；不升级已有 Python 环境依赖。
7. 原始曲库、WAV、Basic Pitch 结果与旧版不得覆盖；新生成结果可显式选用。
8. 推理串行、有进度可取消；GPU 小批次，显存不足时明确失败或安全 CPU 重试。
9. 本轮不训练、不接其他模型、不重构产品架构。
10. 验证真实模型输出/缓存/融合/目录，宽窄窗口与大字体，交付独立开发版与试听对比。
