# SPEC — 弦乐 MIDI 第一版
1. 复用 Basic Pitch，无新模型/环境；XLD 负责生成，XML 继续消费共享结果。
2. 输入为已验证的 Mega53 整曲 strings/strings-all/violin/viola/cello/double-bass 目标原始 WAV。
3. 每首歌一个可选 strings MIDI 槽；默认不加入，明确选择后加入一键和融合，避免组与子声部重复。
4. 30 秒试听结果不转整曲 MIDI；完整音频时间原点为0，保持原曲对齐。
5. MIDI 来源保存 refinement runId/cacheKey，按源和模型隔离缓存；改选恢复对应缓存。
6. UI 增加弦乐来源选择与说明；来源标签展示目标/输入/时长；单轨菜单、试听、目录复用。
7. 可对无基础六轨但已有原曲整曲细分的弦乐单独转谱；一键仅处理可用声部。
8. 保存 GM 弦乐/小提琴/中提琴/大提琴/低音提琴音色编号；音符、控制变化保持时间。
9. 一键固定完整音源集合，途中变化停止；融合按实际激活来源，空音符跳过。
10. 取消/失败保留成功结果；使用中的细分 WAV 被 MIDI 依赖保护，不随存储清理丢失来源。
11. Windows 个人开发版，复用 Electron 与现有 runtime，保留旧发布和原曲/人工标注。
12. 验证接口/控制器/缓存/融合/清理保护、真实弦乐推理回读与隐藏窗口；音准最终由用户试听。
13. v2 backlog：弦乐专用新模型、片段 MIDI 时间偏移、多弦乐独立槽及重叠融合。
