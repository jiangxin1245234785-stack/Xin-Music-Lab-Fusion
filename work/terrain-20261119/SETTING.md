## 已定
- 画面是真的窗外风景，不是剖面图。
- 主角是远山；大片的天属于设定（美西天大地阔），但天要有内容。
- 现代火车，初版带窗框。
- 流程：一个选择一个选择地推敲，每个选择先看草图，不写核心代码。

- **分轨 = 一轨一重山**（用户看了 `mock/phone/01–04` 后选的 A，2026-11-19）。一轨一层岩不要。

- **鼓不当山，改成地面上近处掠过的东西**（用户：「鼓能否改成其他的装饰元素，地面上的？」，看了对应表后「OK，出一版」）。草图里先用：底鼓 = 电线杆，军鼓 = 里程桩 / 信号桩，踩镲 = 围栏木桩，通鼓 = 石堆 / 灌木，吊镲 = 惊起的鸟或风车。对应表还要看图确认。
- 第二轮草图（`mock2/`）：山脚逐重抬高、音符定山脊都做过；用户没明说选 V3，但接受以它为底往下画。

- **鼓 = 路边的东西：未定**（看了 `mock3/` 后用户：「我不能确定，有的歌曲鼓组太密集了可能画面会看起来令人难受，先可以留个不确定」）。要定时先出全曲库鼓密度名单，挑最密的几首出帧和一小段连续画面。退路：太密时只画底鼓和军鼓，或地面元素整体退远变淡。第三轮记账的毛病：风车成排像风电场、军鼓桩不显眼、通鼓石堆太小、远山被磨得太圆。
- **一首歌里光线不变**（用户：「不要时间变化，时间变化本身就是一种情绪」）。在「固定一种光」和「天色取自封面」之间选，草图 `mock4/`。随进度入夜、随起伏变亮暗都不要。

- **光线 = 固定下午斜阳 + 专辑封面轻度取色**（用户看了 `mock4/` 后：「下午斜阳搭配专辑封面取色看起来不错」）。即 mock4 的「轻」：时刻不变，封面只给天边和远处的雾染色，天顶仍是蓝的；灰白封面或没有封面退回纯斜阳。「重」不要。取色和限色的数值是画图助手定的，执行时照 `mock4/` 的做法，暖色封面之间差别很小这一点用户已看过图。

- **音符：试「岩层横纹」**（用户担心音密了画面乱：「山上的什么东西会变得类似于音符般规整呢？」；听了岩层横纹的说法后「可以做一帧试试」）。每重山的迎面是带水平岩层的崖壁，音高 = 崖面上的高低，一个音 = 一段浅色岩带。未定，草图 `mock5/`。电线上的鸟留作人声的备选。「现在」用阳光照亮正在响的岩带，也未定。

- **播放头和文字都属于车厢里，不画在风景上**（用户：「播放头（现在）这个概念应该放在车窗内，确实合理；文字也是同样的」）。车里的显示是 LED 点阵。具体样子未定。
- **开头和结尾 = 大平原**（用户：「开头与结尾就是大平原，没有电线杆，单纯的乏味背景板」）。山从平原里升起、最后沉回平原，首尾没有路边的东西。
