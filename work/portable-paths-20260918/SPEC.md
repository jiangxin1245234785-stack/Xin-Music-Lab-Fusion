# 相对路径与独立预览包
1. 输入：现有 history.1 源码、runtime/0.5.0 与 addons，不更换依赖或模型。
2. 输出：0.5.0-preview.paths.1 新程序目录、相对 runtime.json、路径与搬迁验证报告。
3. 界面：沿用现有曲库/资料库选择、诊断和帮助；新预览用户配置独立，不导入个人开发种子。
4. 目标：Windows；本机真实搬迁验证，干净机器/VM 全流程仍单列发布验收。
5. 路径：环境/权重相对配置文件解析；用户自行选择的音乐与结果绝对路径保留。
6. 失败：跨盘不能相对表示时明确报错；缺环境保留诊断，不自动改用户数据目录或下载。
7. 依赖：沿用 Electron/Python/torch/librosa/numba；仅复用已有环境，不改模型精度与默认。
8. 不变量：旧包、原 runtime、音乐及分析结果不移动、不覆盖；无关并行文档修改不提交。
9. 验证：相对/旧绝对配置兼容、不同 cwd、中文空格路径、重定位、共享 Python、首次默认、真实短段推理。
10. 交付：本地预览包和 GitHub 源码；不公开仓库、不创建对外发行 Release。
11. 后续：模型安装/更新页、许可处理、更多硬件和干净系统验收，不在本轮加入新模型。
