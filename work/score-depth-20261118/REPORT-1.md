# 谱面做深 · 第一批（鼓、短音）报告（2026-11-18）

## 结论

- 五款基础款（星空、压纹纸、余烬、夜水、声雾）的鼓和短音都改了，核心 0.29.0。本地已提交一笔，没推送。
- **鼓**：
  - 记法只有一套，在核心里，五款共用（`XinScoreView.drumKit`）。
  - 鼓轨固定五行，从上到下：镲、踩镲、通鼓、军鼓、底鼓。不管歌里的行是什么顺序、这一行打没打，位置都不变。
  - 记号：底鼓扁圆、军鼓菱形、通鼓圆点、踩镲斜线（开镲两道）、吊镲交叉、叮叮镲斜线加底。
  - 各款只换材质：星空是轨色的光点，压纹纸是墨，余烬未来是灰白、击中一刻橙色，夜水是淡蓝水滴加涟漪，声雾用它自己的墨。
  - 各款原来的时间感不变：星空过线后照「鼓的衰减」设置淡掉，余烬烧过就没，压纹纸在墨的窗口里，夜水击中时起涟漪。
- **短音**：短于 0.3 秒的音，起音处画一个圆点（缺省半径 2.2 像素）；长音还是点加线，线没加粗。新选项 `shortHead`，0 就回到原样。
- 要用户挑的：短音的头多大，A 1.6 / B 2.2 / C 2.8（`phone/16`、`17`）。
- 测试三套都绿：谱面 449 条（448 过、1 条本来就跳过），XML、XLD 的 `npm test` 都过。
- 帧耗时没有变重。只有声雾平均多了约 0.1 毫秒，是多画的圆头；最长一帧不比原来长。
- **这一版最可能露馅的一帧**：MEGURI 8:20，鼓最密处。底鼓十六分音符一下挨一下，在正常倍率下连成一条（`phone/11–15`）。

## 验收的瞬间

- **鼓**：七里香副歌（1:40）暂停，只看鼓那几行。踩镲一行斜线等距排开，能数出拍子；军鼓的菱形在第二、四拍；底鼓扁圆在最下面一行（`phone/01–05`）。
  - 星空、余烬、夜水的「过去」那一侧，照各款原来的时间感很快淡掉，拍子主要在播放线右边数。这是各款原有的设置（星空跟着 XML 里「鼓的衰减」开关，缺省开），这次没动。
- **短音**：七里香 4:07 钢琴，碎的短音是一个个圆点，长音拖着线，分得出谁短谁长（`phone/06–10`）。
  - 文件名写「4:46」的 `review/` 图是只有短音的一段，只用来比头的大小。

## 改了哪些文件

- `source/scoreview/score-view.js`（0.29.0）：
  - `DRUM_KIT`、`kitMark` / `kitCenter` / `kitSize`，导出为 `drumKit`；
  - 核心自己的鼓（星空和普通记谱）改用它，五行代替原来的七行，记号上限 4.2 像素半高（原来约 2.7）；
  - `SHORT_NOTE`、新选项 `shortHead`，星空里未来的短音用它画头。
- `source/scoreview/score-surface.js`：
  - 压纹纸 / 余烬 / 夜水的鼓：按 `drumKit` 的行和记号画，各用自己的颜色；
  - 新加 `shortHeads`：三款的短音圆头，过去 / 正在响 / 未来各用自己的墨。
- `source/scoreview/score-mist.js`：声雾的鼓按 `drumKit` 画，短音加圆头。
- `source/scoreview/MODEL.md`：`drumNotation` 那条改成五行一套记法，新加 `shortHead`。
- **测试：**
  - 7 处版本号；
  - `drum-notation.test.cjs`：认不出的打击乐现在都在通鼓那一行；
  - `meteor-motion.test.cjs`：鼓记号的路径里多了 `roundRect`。
- 导出：`score-presentation.js` 的导出选项本来就沿用播放器的选项，`drumNotation`、`shortHead` 会一起带进导出，所以没改。没有重新导出视频做逐像素对照（见「没验证的事」）。
