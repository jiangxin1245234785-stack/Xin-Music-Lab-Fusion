## 结论

- 两笔本地提交，都没推送：
  - **acb90dd**（核心 0.29.1）：短音的头缺省改成用户选的 A（1.6 像素）；连打的鼓记号之间留缝，MEGURI 8:20 的底鼓一下一下数得出。
  - **第二批这一笔**（核心 0.30.0）：星空做成真夜空；原来的星空画法另留成一款「原样」（`plain`）。
- **星空现在是这样**（对应表照 `work/score-redesign-20261116/README.md`「星空」）：
  - 天：一种静止的深蓝黑，只取封面的色相、不取它的亮度，所以亮封面也不会把天抬灰；不再随段落换色、随响度呼吸。
  - 没弹到的音是暗星：起音处一个暗点，长度只剩一根更淡的细线。
  - 弹拨的音过线时是流星，尾巴在音结束后 1.5 秒内淡尽。
  - 长音是星轨（原有的画法）。
  - 播放线是地平线：一道静止的柔光加一根细线，顶上的圆点去掉了。
  - 「其它」带子是银河：浅白蓝的光，边更柔。
  - 三条硬规矩守着：星星不闪，不撒没有对应音的星，背景是静的。
- 要用户挑的：暗星多暗（A 0.22 / B 0.34 现在 / C 0.48，`phone-2/07`）；流星尾巴多久淡尽（A 1 / B 1.5 现在 / C 2.2 秒，`phone-2/08`）。
- 测试三套都绿：谱面 454 条（453 过、1 条本来就跳过），XML、XLD 的 `npm test` 都过。
- 帧耗时：星空平均比改前多 0.03–0.07 毫秒，最长一帧 3.5 毫秒（没有超过 4 的）；「原样」和改前一样。
- **最可能露馅的一帧**：封面颜色染天色。做的时候真露馅过一次：很亮的暖色封面把天染成了灰色，已改成只取色相（`phone-2/10`）。

## 先核实 / 说明

- **流星尾巴和 XML 的「拨弦淡出」设置：**
  - XML 设置里本来有一个「拨弦淡出」的时长（自然 0.70 秒，`pluckReleaseSeconds`）。
  - 新星空里流星尾巴用的是 `meteorTail`（1.5 秒），所以那个设置现在只管「原样」这一款。
  - 用户挑了尾巴长短之后，要不要把两者合成一个设置，是下一步的事。
- **天色：** 任务书说取自封面，这里取的是封面平均色的色相、压到天的亮度。没有封面的歌（七里香）就是固定的深蓝黑。
- **轨的分行：** 轨底的极淡分行带保留，「每条轨各占一行」不变。鼓仍是第一批的记号，在夜空里没另画。
