# Mega53 全目标开发版
1. 输入：当前歌曲原文件，或当前六轨结果中的任一轨；单曲、单目标，默认 other。
2. 全部 53 个原始输出头一一开放，中文分类与目标选择；保留 strings 对 bowed_strings 的旧身份。
3. 输出：FLOAT WAV 原始/目标/残差、必要时共用增益试听副本；独立缓存，不覆盖已有结果。
4. 界面：沿用 Electron XLD；来源、分类、目标、设备、整曲/30秒、起点、执行/取消/试听/目录/保留。
5. Mega 支持原曲与各轨；Bowed/AudioSep 保持 other 预览；默认仍 Mega/弓弦乐/整曲/自动。
6. 目标机器：用户现有 Windows 和已安装独立 Python/模型运行时；无新增依赖或权重。
7. 解码：现有 soundfile；不新增 ffmpeg，不承诺所有容器格式均可读取。
8. 失败：单次任务报错，保留先前缓存；可取消；无自动并行 53 轨任务。
9. 原曲从可信曲库索引读取；来源/模型/目标/范围隔离缓存，旧 other 缓存可直接读取。
10. 验证：53 项与模型配置对应、源选择/缓存/取消/界面状态、真实音频推理与包完整性。
11. 发布：独立 0.5.0-dev.mega2，保留 RC.6/mega1；本机验证，不宣称干净 VM 或听感验收。
12. v2 backlog：批量全部目标导出、自动音轨合并、更多模型、MIDI 接入。
