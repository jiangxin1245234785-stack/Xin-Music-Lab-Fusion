# 分轨 v1（已按用户计划冻结）
1. 输入：当前单曲 WAV/FLAC/MP3；本机单任务，不做跨程序调度。
2. 输出：htdemucs_6s 实际六声部，float32 双声道 WAV，模型采样率，统一长度与零点。
3. 数据：每曲独立 stems.json；按源路径/大小/mtime、模型/参数复用。
4. 重跑：先生成新文件，清单提交后替换；取消/失败保留旧成功结果与人工标签。
5. 界面：XML 现有分析面板增加分轨/重新分轨、音轨选择、打开输出目录；复用进度/取消/播放/定位。
6. 目标：当前 Windows + 现有 XLD Python/CUDA 环境；首版是本机开发版，不制作独立 exe。
7. 依赖：复用 torch/demucs/soundfile/torchaudio；WAV/FLAC/MP3 用 soundfile 解码，不新增 librosa 或 ffmpeg。
8. 后端：独立 runner + JSON 行进度；未来可替换，不建设插件框架。
9. 优化：即时任务占用、启动失败释放、取消重试、简单追加日志、局部分析旧结果保留。
10. 验证：任务回归 + 真实短片段与一首完整歌曲 + 开发界面试听/重新读取。
11. 不变量：不修改原音频/人工标签，不修改安装目录，不改变现有视觉语义。
12. v2 backlog：跨程序队列、批处理、MIDI、混音、内容指纹、完整历史、独立安装包。
