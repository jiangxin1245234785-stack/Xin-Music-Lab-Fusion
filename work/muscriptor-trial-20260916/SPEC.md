# MuScriptor Medium 吉他试听
- 输入：既有 MEGURI / BS-RoFormer SW guitar.wav 与同源 GAPS MIDI。
- 输出：独立 MIDI、三个 30 秒同片段试听、中文对比页与运行记录。
- 策略：官方 Medium 权重与解码，指定支持的吉他类别，使用官方分块解码；强制延音模式异常记录保留。
- 不进行音符修补、自动碎音合并或默认模型切换。
- Windows 本地 CUDA；只读复用已装依赖，不修改现有产品运行环境。
- 依赖：复用已有 Torch CUDA，按官方代码核实其他依赖；试听复用 SoundFont。
- 权重：官方 Hugging Face，需要有效访问授权；不绕过下载限制。
- 失败：保存进度/日志；访问受限时等待账户授权，其他准备继续。
- 验证：权重来源、CUDA、MIDI 回读、输入哈希不变、试听加载。
- 交付为本机试听，不打包 exe 或修改 XML/XLD 产品。
