# 单曲一键 MIDI
1. MIDI 页增加一键入口，已分轨歌曲可依次生成 bass、piano、guitar，然后融合。
2. 使用每个声部记住的模型，否则沿用可用默认模型；启动前展示计划。
3. 已有有效结果复用；“重新生成”只影响本次三个 MIDI，不重新分轨。
4. 开始后固定歌曲、模型、WAV 来源和重新生成选项，不切换试听声部。
5. 复用当前 XLD 批处理状态、串行执行接口、进度和取消，不增加后台服务。
6. 失败或取消立即停止后续步骤，保留成功结果；再次点击复用已有结果。
7. 无有效 WAV 时提示先分轨。用户仍可单声部生成或单独融合。
8. 不增加依赖、模型或打包；验证计划、取消、失败、来源变更及真实缓存界面后交付开发源。
