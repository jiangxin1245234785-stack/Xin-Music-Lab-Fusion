# XLD 分析职责归位
1. 输入：当前本机单曲及已有分轨；继续使用原 Track ID 和分析目录。
2. 输出：原 stems.json、六轨 WAV、单声部 MIDI/notes.json、段落/和弦及 music-lab.json；清单格式不变。
3. XLD 拥有可导入分析核心及分轨/MIDI CLI；XML 只调用该核心，保留兼容入口。
4. XLD GUI 增加分轨、生成 MIDI、重新生成选项；复用统一任务进度和取消按钮，保留试听、刷新及目录操作。
5. 分轨、MIDI、段落、和弦共用每个宿主内的一个任务执行器；本轮不增加常驻服务和跨进程队列。
6. 保留旧结果直到新结果完成校验；人工标签单独保存，失败/取消记日志并允许重试。
7. Windows 本机开发版；沿用 Electron 与已验证的 Python/Demucs/Basic Pitch 环境，不安装依赖或打包 EXE。
8. XML 界面说明分析由 XLD 提供；已有分轨/MIDI 缓存兼容，不搬迁用户音频。
9. 回归现有段落局部分析、和弦预处理、时间线、人工标签与分轨试听。
10. 验证核心归属、任务互斥/取消/失败、XLD 真实音频分轨与 MIDI 入口、XML 兼容调用和双端读取。
11. 交付可编辑源码、开发启动器及最新职责文档；不覆盖安装产品。
12. 后续再议：跨程序任务互斥、独立安装包、MIDI 编辑器。
