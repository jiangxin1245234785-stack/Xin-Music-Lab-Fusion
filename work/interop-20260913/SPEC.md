# XML / XLD 结果互通 v1
1. 目标：XML 生成，XLD 读取同一份六轨 WAV 与 MIDI；不重新推理或复制音频。
2. 开发：新增 source/xld-runtime-baseline；保留安装产品，复用现有 Python 与模型。
3. 共享：一个本地 derived-assets.cjs，负责目录定位、分轨/MIDI 读取及校验。
4. 身份：沿用 Track ID 与磁盘路径字段，兼容之前按显示名称创建的目录。
5. XML：继续保留分轨、转谱入口；内嵌服务改用共享读取模块。
6. XLD：所选歌曲增加音轨选择、试听、刷新、WAV 目录、MIDI 目录及状态。
7. 播放：单击选曲仍不播放；点击试听才播放所选音轨；同曲切轨保留位置与播放状态。
8. 切歌：普通播放新曲回到原曲；声部试听沿用母曲身份、段落时间线及原队列。
9. 刷新：选曲、手动刷新与窗口重新获得焦点时读取；结果失效时清楚提示并回到原曲。
10. 配置：沿用 XLD 的曲库/分析目录设置；XML 高级评测台优先打开 XLD 开发版。
11. 验证：共享读取一致、缺失/过期、真实 WAV 试听与位置、切歌、重开、原时间线/标签。
12. 本轮不做：XLD 发起分轨/MIDI、共享队列、数据库、模型改动、MIDI 播放或安装包。
