# 单轨 MIDI v1
1. 输入：当前母曲已有的 bass、piano 或 guitar 分轨 WAV；一次一轨。
2. 输出：MIDI 与带秒级时间的音符 JSON；保持母曲时间原点，不自动量化。
3. MIDI 使用固定 120 BPM 编码秒级时间，不将其当成检测到的歌曲速度。
4. 关联：记录 Track ID、stem 名称与分轨 runId；重分轨后旧转谱不视为当前结果。
5. 界面：复用音轨选择，增加「转 MIDI」「打开 MIDI 目录」及文字状态；复用分析进度/取消。
6. 推理：Basic Pitch 0.4.0 + ONNX CPU，独立 Python 3.10 环境；保持现有分轨/段落环境。
7. 依赖：Basic Pitch 本身需要 librosa/numba；固定环境依赖，不另加 ffmpeg，不制作独立 exe。
8. 任务：沿用单任务互斥、追加日志、先写临时结果，成功后发布；失败/取消保留已有结果。
9. 缓存：同分轨 runId、模型、参数命中；重新转谱保留当前旧结果直到成功。
10. 空结果：明确显示未识别到音符；不把它描述为已成功转谱。
11. 验证：真实已分离 WAV 转谱、MIDI/JSON 时间一致性、缓存及取消/失败保留、界面入口。
12. 暂缓：内置钢琴卷帘、MIDI 播放、批量、自动拍速/拍号、量化、动机识别。
